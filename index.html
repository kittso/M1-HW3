題目一：極限（Limits）— 分子有理化與基礎指數模型

［滿分：5分］

(a) 求 $\lim_{x \to 0} \frac{\sqrt{x^2+9}-3}{x^2}$ 的值。 (3分)

(b) 某研究指一個生態島嶼上的某種鳥類數量 $N(t)$ 隨時間 $t$（以年為單位）的變化可用以下模型模擬： $$N(t) = \frac{5000}{2 + 3e^{-0.15t}}$$ 求當時間過去一段極長時間後，島上鳥類數量的極限值。 (2分)

(b) 某科技產品推出 $t$ 個月後的月產量 $P(t)$（以千件為單位）可用以下模型模擬： $$P(t) = \frac{40t^2 + 150}{2t^2 + t + 5}$$ 求當該產品推出一段極長時間後，月產量的極限值。 (3分)

題目五：極限（Limits）— 分母有理化與複合變率模型

［滿分：5分］

(a) 求 $\lim_{x \to 0} \frac {x^2 + 2x}{\sqrt{x+4}-2}$ 的值。 (3分)

(b) 某網店的每日瀏覽人數變率 $R(t)$（以人／日為單位）由以下模型模擬： $$R(t) = 500 - 300e^{-0.2t} + \frac{80}{t+1}$$ 其中 $t \ge 0$ 為網店開張後的天數。求當 $t \to \infty$ 時，每日瀏覽人數變率的極限值。 (2分)

📢 老師閱卷提點： 對答案時請嚴格檢查學生的步驟。M mark (Method mark) 代表方法正確即可給分，A mark (Answer mark) 代表答案及前面步驟必須完全準確。特別留意不定積分答案背後有沒有寫 $+ C$，漏寫則該 A mark 扣至 0 分。

題目一：評卷參考（Limits — 分子有理化）

解 (a)
進行分子有理化（Rationalization）：
$$\lim_{x \to 0} \frac{\sqrt{x^2+9}-3}{x^2} = \lim_{x \to 0} \frac{(\sqrt{x^2+9}-3)(\sqrt{x^2+9}+3)}{x^2(\sqrt{x^2+9}+3)}$$ 1M $$= \lim_{x \to 0} \frac{(x^2+9) - 9}{x^2(\sqrt{x^2+9}+3)} = \lim_{x \to 0} \frac{x^2}{x^2(\sqrt{x^2+9}+3)}$$ $$= \lim_{x \to 0} \frac{1}{\sqrt{x^2+9}+3}$$ 1M 代入 $x = 0$： $$= \frac{1}{\sqrt{0+9}+3} = \frac{1}{3+3} = \frac{1}{6}$$ 1A 答案： $\frac{1}{6}$
解 (b)
當 $t \to \infty$ 時， $-0.15t \to -\infty$，因此 $e^{-0.15t} \to 0$。 1M $$\lim_{t \to \infty} N(t) = \lim_{t \to \infty} \frac{5000}{2 + 3e^{-0.15t}} = \frac{5000}{2 + 3(0)} = 2500$$ 1A 答案： 鳥類數量的極限值為 $2500$ 隻。

題目二：評卷參考（Substitution）

解 (a)
設 $u = 2x+1 \implies x = \frac{u-1}{2}$ 且 $dx = \frac{1}{2}du$。 1M
$$\int \frac{x}{\sqrt{2x+1}} \, dx = \int \frac{\frac{u-1}{2}}{\sqrt{u}} \cdot \left(\frac{1}{2}du\right) = \frac{1}{4} \int \left( u^{\frac{1}{2}} - u^{-\frac{1}{2}} \right) \, du$$ 1M $$= \frac{1}{4} \left[ \frac{2}{3}u^{\frac{3}{2}} - 2u^{\frac{1}{2}} \right] + C = \frac{1}{6}u^{\frac{3}{2}} - \frac{1;}{2}u^{\frac{1}{2}} + C$$ 1M $$= \frac{1}{6}(2x+1)^{\frac{3}{2}} - \frac{1}{2}(2x+1)^{\frac{1}{2}} + C$$ 1A
解 (b)
代入 $(4, 2)$ 到 $y = \frac{1}{6}(2x+1)^{\frac{3}{2}} - \frac{1}{2}(2x+1)^{\frac{1}{2}} + C$：
$$2 = \frac{1}{6}(9)^{\frac{3}{2}} - \frac{1}{2}(9)^{\frac{1}{2}} + C \implies 2 = 4.5 - 1.5 + C \implies C = -1$$ 1M + 1A 答案： 該曲線方程為 $y = \frac{1}{6}(2x+1)^{\frac{3}{2}} - \frac{1}{2}(2x+1)^{\frac{1}{2}} - 1$ 1A

題目三：評卷參考（Recognition）

解 (a)
$$\frac{d}{dx} (x^2 \ln x) = \ln x \cdot (2x) + x^2 \cdot \left(\frac{1}{x}\right) = 2x\ln x + x = x(2\ln x + 1)$$ 1M + 1A
解 (b)
根據 (a) 部結果： $x^2 \ln x = \int (2x\ln x + x) \, dx = 2\int x\ln x \, dx + \frac{1}{2}x^2 + C_1$ 1M + 1M
移項得： $\int x\ln x \, dx = \frac{1}{2}x^2 \ln x - \frac{1}{4}x^2 + C$ 1A

題目四：評卷參考（Limits — 因式分解與無限大極限）

解 (a)
當 $x \to 3$ 時分子分母均為 $0$。進行因式分解以消除零因子 $(x-3)$：
$$\lim_{x \to 3} \frac{x^2 - 2x - 3}{x^2 - 9} = \lim_{x \to 3} \frac{(x-3)(x+1)}{(x-3)(x+3)}$$ 1M $$= \lim_{x \to 3} \frac{x+1}{x+3} = \frac{3+1}{3+3} = \frac{4}{6} = \frac{2}{3}$$ 1A 答案： $\frac{2}{3}$
解 (b)
「推出一段極長時間」即求當 $t \to \infty$ 時的極限。將分子分母同除以最高次項 $t^2$：
$$\lim_{t \to \infty} \frac{40t^2 + 150}{2t^2 + t + 5} = \lim_{t \to \infty} \frac{40 + \frac{150}{t^2}}{2 + \frac{1}{t} + \frac{5}{t^2}}$$ 1M
當 $t \to \infty$ 時， $\frac{150}{t^2} \to 0$、 $\frac{1}{t} \to 0$ 且 $\frac{5}{t^2} \to 0$：
$$= \frac{40 + 0}{2 + 0 + 0} = \frac{40}{2} = 20$$ 1A 答案： 月產量的極限值為 $20$ 千件（即 $20,000$ 件）。 1A

題目五：評卷參考（Limits — 分母有理化與複合模型）

解 (a)
代入 $x=0$ 出現 $\frac{0}{0}$ 形式，需要進行分母有理化：
$$\lim_{x \to 0} \frac{x^2 + 2x}{\sqrt{x+4}-2} = \lim_{x \to 0} \frac{(x^2+2x)(\sqrt{x+4}+2)}{(\sqrt{x+4}-2)(\sqrt{x+4}+2)}$$ 1M $$= \lim_{x \to 0} \frac{x(x+2)(\sqrt{x+4}+2)}{(x+4)-4} = \lim_{x \to 0} \frac{x(x+2)(\sqrt{x+4}+2)}{x}$$ 消去分子分母的零因子 $x$：
$$= \lim_{x \to 0} (x+2)(\sqrt{x+4}+2)$$ 1M 代入 $x = 0$： $$= (0+2)(\sqrt{0+4}+2) = 2 \times (2+2) = 8$$ 1A 答案： $8$
解 (b)
當 $t \to \infty$ 時，分析各獨立項的趨勢：
1) 因為 $-0.2t \to -\infty$，所以其指數項 $e^{-0.2t} \to 0$。
2) 因為分母無限變大，所以分數項 $\frac{80}{t+1} \to 0$。 1M
因此，每日瀏覽人數變率的極限值為： $$\lim_{t \to \infty} R(t) = 500 - 300(0) + 0 = 500$$ 1A 答案： 每日瀏覽人數變率的極限值為 $500$ 人／日。
